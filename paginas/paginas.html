Estáticas:

Las páginas estáticas son páginas web cuyo contenido siempre es el mismo y no cambia automáticamente. Están creadas principalmente con HTML y CSS, y muestran información fija para todos los usuarios.

Páginas dinámicas:

Las páginas dinámicas son páginas web cuyo contenido puede cambiar según el usuario, la hora o la información almacenada en una base de datos. Utilizan lenguajes como JavaScript, PHP o Python para generar contenido de forma automática e interactiva.
