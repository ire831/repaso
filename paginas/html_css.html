HTML

HTML es un lenguaje de programación utilizado para crear la estructura de una página web. Sus siglas significan HyperText Markup Language (Lenguaje de Marcado de Hipertexto). Con HTML se pueden crear títulos, textos, imágenes, enlaces, tablas, menús y muchos otros elementos que aparecen en una página web. HTML funciona mediante etiquetas que indican al navegador cómo debe mostrar el contenido. Por ejemplo, la etiqueta h1> crea un título y la etiqueta /p> crea un párrafo. Gracias a HTML, los navegadores pueden interpretar y mostrar correctamente la información de un sitio web.

CSS

CSS se utiliza para dar diseño y estilo a una página web. Gracias a CSS se pueden cambiar colores, tamaños, fuentes, fondos, márgenes y la posición de los elementos. También permite crear menús, animaciones y diseños adaptados a móviles y ordenadores. Mientras HTML crea la estructura de la página, CSS se encarga de hacer que la web tenga una apariencia más profesional, ordenada y atractiva para los usuarios.

Ejemplo:

body {
    background-color: #f0f2f5;
    color: #333;
}
