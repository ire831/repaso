🌐 Dirección IP:

Una dirección IP es un número único que identifica a cada dispositivo conectado a Internet o a una red. Sirve para que los equipos puedan comunicarse y enviar información entre sí. Es parecida a una dirección postal, pero en Internet.

🧭 DNS:

El DNS (Domain Name System) es un sistema que traduce los nombres de las páginas web en direcciones IP. Gracias al DNS, las personas pueden escribir nombres fáciles de recordar en lugar de números largos.

🔒 Protocolos HTTP y HTTPS:

HTTP y HTTPS son protocolos utilizados para transferir información entre el navegador y el servidor web. HTTPS es la versión segura de HTTP porque cifra los datos y protege la información del usuario.

📡 Servidores y clientes:

El cliente es el dispositivo o navegador que solicita información, mientras que el servidor es el ordenador que almacena y envía los archivos de la página web. Ambos trabajan juntos para mostrar el contenido al usuario.

📦 Transferencia de datos por la red:

La transferencia de datos es el proceso mediante el cual la información viaja de un dispositivo a otro a través de Internet. Esto permite enviar y recibir archivos, imágenes, vídeos y páginas web rápidamente.

🖥️ Navegador:

Un navegador es un programa que permite acceder y visualizar páginas web en Internet. Interpreta el código HTML, CSS y JavaScript para mostrar correctamente los sitios web.

🌍 Sitio web:

Un sitio web es un conjunto de páginas conectadas entre sí que contienen información y pueden visitarse a través de Internet.

👨‍💻 Administrador:

El administrador es la persona encargada de gestionar y mantener un sitio web, servidor o red informática. Se ocupa de controlar el funcionamiento y la seguridad del sistema.

💻 Sitio local:

Un sitio local es una página web que se ejecuta únicamente en un ordenador sin estar publicada en Internet. Se utiliza normalmente para pruebas y desarrollo.

📡 TCP/IP:

TCP/IP es el conjunto de protocolos que permite la comunicación entre dispositivos conectados a Internet. Se encarga de enviar y recibir datos correctamente.

📁 FTP:

FTP es un protocolo utilizado para transferir archivos entre ordenadores a través de una red o Internet.

🌐 ISP:

Un ISP es una empresa que proporciona acceso a Internet a los usuarios y empresas.
