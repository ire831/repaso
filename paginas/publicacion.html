🚀 Servidores y plataformas

Los servicios y publicaciones en la red permiten compartir información y comunicarse a través de Internet. Estos servicios facilitan el acceso a contenidos, noticias, archivos y herramientas desde cualquier lugar del mundo. Entre los principales servicios se encuentran las páginas web, el correo electrónico, las redes sociales y las plataformas de vídeo o almacenamiento. Todos ellos ayudan a las personas y empresas a publicar información y mantenerse conectadas. Las publicaciones en la red son los contenidos que se suben a Internet, como noticias, imágenes, vídeos, artículos o anuncios. Su objetivo es informar, entretener o dar a conocer productos y servicios a los usuarios. Se puede usar GitHub Pages para publicar tu proyecto web de manera gratuita.

📦 Cómo subir tu proyecto

Para subir un proyecto a Internet con GitHub se utiliza un repositorio, que es un espacio donde se guardan los archivos del proyecto. Primero, se crea una cuenta en GitHub y después un nuevo repositorio. Una vez creado, se suben los archivos del proyecto, como HTML y CSS, usando GitHub Desktop o comandos de Git. Después de subir los archivos, se puede activar GitHub Pages, un servicio que permite publicar páginas web gratuitamente. Al activarlo, GitHub genera un enlace para que cualquier persona pueda visitar el sitio web desde Internet. Este método es muy utilizado porque es gratuito, sencillo y permite guardar copias del proyecto y actualizar la página web fácilmente.

🌐 Cómo funciona GitHub Pages

GitHub Pages funciona como un servicio de alojamiento web gratuito de GitHub que permite publicar páginas web directamente desde un repositorio. Cuando el usuario sube los archivos de su proyecto, como HTML, CSS y JavaScript, GitHub los guarda y los convierte en un sitio web accesible desde Internet.
